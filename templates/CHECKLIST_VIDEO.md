# Checklist de aprobación final por video

- [ ] ID proyecto y versión/sha256 de render anotados.
- [ ] Investigación con fechas, fuentes y evidencias vinculadas.
- [ ] Claims criminales sensibles revisados, lenguaje judicial preciso.
- [ ] Todas las imágenes/videos/audio con licencia o autorización de uso comercial.
- [ ] Recreaciones IA con rótulo y sin presentarlas como archivo auténtico.
- [ ] Gancho original y sin afirmaciones engañosas.
- [ ] Audio español LATAM, mezcla clara, subtítulos y safe areas revisados.
- [ ] MP4 H.264/AAC, 1080×1920 y 120–240 s con ffprobe.
- [ ] Títulos/copy aprobados; Page/cuenta correcta y conexión válida.
- [ ] Presupuesto real dentro del cap y no se repetirá TTS innecesariamente.
- [ ] Aprobación del revisor de **este hash de render**, timestamp y audit registrado.
- [ ] Publicar solo por API oficial; verificar remote_id y métricas disponibles.
